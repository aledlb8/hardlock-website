Every aircraft and weapon number in Hardlock comes from a **public figure** (Wikipedia, a manufacturer brochure, a service fact sheet, a published paper), from **published game data**, or is **built for the game** from public geometry, textbook physics and comparable types, then tuned for gameplay. Classified or export-controlled data is never used, wanted or reconstructed.

**Cards and this guide show each value plainly**, as the number the game flies. Where each value comes from is recorded with it in the game's data, not printed on screen.

## Public first, game data second

The game uses a public figure whenever one exists, and fills a gap from another game's published stat card only when public sources say nothing. When the two disagree, the public figure wins: the F-15C flies its public +9 g, not the +12 on a game card, and the F/A-18E flies its public +7.5 g, not +11.

- **A brochure weight is not a flying weight.** Every jet flies its combat weight, with half its internal fuel, two missiles and a pilot aboard.
- **A speed limit is not a top speed.** Each jet's drag is set so it reaches its card's speeds on full afterburner. The F-16 flies past the 1,555 km/h airspeed limit printed for it, because the game does not enforce limits.
- **When nothing is public, build it.** A missing value is worked out from the aircraft's or missile's public size and weight with textbook methods, or from comparable types, and then flown like any other.

## What the game's own cards show

The hangar and tactical-screen cards list the values the game flies, all in the same plain style. A radar missile's card leaves off what changes nothing in flight, such as its datalink type or range claims.

## What the numbers are not

The radar, seekers, warning displays and countermeasures are gameplay, built from simplified textbook models so the game feels plausible. **They are not a model of any fielded weapon**, and no number here predicts real performance. Some values are set for play because the real number is not public: every radar missile's own seeker switches on at 16 km for that reason.
