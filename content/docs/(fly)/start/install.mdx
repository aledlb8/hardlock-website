## What you need

- 64-bit Windows 10 or 11.
- A graphics card whose driver supports **Vulkan 1.3**. If the game says it can't find it, update your graphics driver first.

Nothing else needs installing.

## Installing

The game comes as a zip named `Hardlock-<version>-win64.zip`.

1. Extract the **whole** zip somewhere, such as your Desktop or Documents. Keep `Hardlock.pak`, the game's data, next to `Hardlock.exe`.
2. Double-click `Hardlock.exe`. A short intro plays while the game loads; <Key k="Esc" />, <Key k="Enter" />, <Key k="Space" /> or a click skips ahead to the title.
3. Choose **START ENGAGEMENT** on the title screen, then **LAUNCH** on the briefing map.

<Callout kind="note" title="SmartScreen warning">
  The game is not code-signed, so Windows SmartScreen may say it comes from an unknown publisher. Click **More info**, then **Run anyway**.
</Callout>

If the game can't start, for example on a graphics card without Vulkan 1.3, it shows a dialog explaining why.

## Files it creates

Everything the game writes goes in `%LOCALAPPDATA%\Hardlock` (paste that into the Explorer address bar), never next to `Hardlock.exe`, so the game can live in a folder Windows will not let it write to:

| File | What it is |
| --- | --- |
| `user_settings.ini` | Your settings and keys. Delete it to go back to the defaults. |
| `scenarios\` | Scenarios you save. Copy a `.json` file here to add someone else's. |
| `raids\` | Raid tables exported from the scenario editor. |
| `custom_setup.json` | The briefing's CUSTOM setup. |
| `screenshots\` | <Key k="F12" /> screenshots. |
| `hardlock.log` | A log of this run, with `hardlock.prev.log` the run before. Send them along if something goes wrong. |

A version that kept these in a `config` folder next to the game has them copied across on the first start.

Settings save themselves as you change them. There is no save button.
