One machine runs the match and everyone else joins it. Every pilot flies their own jet with their own missiles, radar, warning receiver and gun, and the computer pilots fight, or fly with, every player as they would one. A pilot can join on either side, so the same match can be friends against the computer, friends against each other, or both.

Choose **MULTIPLAYER** on the title screen. At the top, type the **callsign** the others see (up to 24 letters; left empty you fly as Pilot), pick your **Side**, and check the **AIRCRAFT** box: you fly that jet with the missiles the [hangar](/world/game-flow/#the-hangar) arms it with, whether you join or host. Click the box to change it in the hangar; BACK there returns to this screen. The callsign, side, address and port are remembered for next time.

## Joining

Games on your home network list themselves under **ON YOUR NETWORK**, on the right, with their scenario, how many are flying and how quickly they answer: click one to join it. Otherwise type the host's address under **JOIN A MATCH**, with `:port` after it if they host on a port other than **27015**, or the **join code** their game gave them (twelve letters and digits, such as 7GQ4-X2MK-9TRA), and press **JOIN** (<Key k="Enter" />). Until you are in, the button reads CANCEL · CONNECTING TO and the address; it, or <Key k="Esc" />, gives up. You then fly in the host's scenario, by its rules, on your side.

A game of another version shows as OTHER VERSION and cannot be joined.

### The server list

A server list keeps the internet servers that tell it they are up. Type its address under **SERVER LIST** and press **REFRESH**: its servers show below, as the ones on your network do. Anyone can run one (see [Running a server](#running-a-server)); there is none by default.

The host's match is only borrowed: when you leave, your menus are as you left them, your own scenario, aircraft and role included.

## Hosting

Under **HOST A MATCH**, set the port (27015 unless you want another), then either:

- **SET UP AND HOST** (<Key k="B" />) opens the briefing map. Set the match up as usual; its main button reads **HOST** instead of LAUNCH.
- **HOST NOW** (<Key k="H" />) hosts the match the briefing already has set up, shown on the **Match** line.

You fly in the match as usual, on the blue side, and others can join from then on. Base defence can't be hosted: the screen reads "Base defence is for one player", HOST NOW stays dark and the briefing's button reads SOLO ONLY until another mode is set.

Under **WHEN YOU HOST**, on the right:

- **Open the port on the router** (on): hosting asks your router to send the port to your PC. When it does, the chat gives you the address friends over the internet join at and its **join code**, copied for you to paste to them, and the top line shows CODE and the code. When it cannot, the chat says why: see [Reaching the host](#reaching-the-host).
- **List my game** (off; there once a server list's address is set): while you host, the server list shows your game.

The pause menu runs the session: **RESTART THE MATCH** starts it again for everyone, **CHANGE THE MATCH** sets up another one, and **END THE MATCH** (or the title screen) ends it for all.

### Changing the match

CHANGE THE MATCH, or **CHANGE MATCH** (<Key k="B" />) on the debrief, opens the briefing map while everyone stays connected. The others see **NEXT MATCH** and wait. Set up any scenario, terrain and weather but base defence, and press **START FOR ALL**: every player is taken into the new match, in their own jet. **KEEP THE LAST MATCH** (<Key k="Esc" />) puts your setup back and starts the last match again instead. Players who join meanwhile wait with the others.

## Running a server

`hardlock_server.exe`, next to the game, runs a match with no window and no pilot of its own, for as long as it is left running. Every pilot in it is someone who joined. Start it from a Command Prompt in the game's folder (type `cmd` in Explorer's address bar there):

```
hardlock_server.exe --name "Friday night" --max-players 8
```

<Facts>
  <dt>--port</dt><dd>UDP port to listen on (27015)</dd>
  <dt>--name</dt><dd>the name players see</dd>
  <dt>--max-players</dt><dd>how many may join (16)</dd>
  <dt>--scenario</dt><dd>a shipped scenario's name, or a scenario file (Sandbox). Give it more than once for a rotation.</dd>
  <dt>--seed</dt><dd>the world's seed (from the clock)</dd>
  <dt>--upnp</dt><dd>ask the router to open the port, and print the join code</dd>
  <dt>--list-on</dt><dd>tell a server list (its address, port 27017 unless given) the server is up</dd>
</Facts>

Games on the same network find a server by themselves. `hardlock_server.exe --master` runs a server list instead of a match: servers that name it with `--list-on` are listed, and games that give its address see them. It listens on UDP port 27017 unless given `--port`.

A server plays its scenario for everyone who joins, by the scenario's own rules, and starts the next match **15 seconds** after one ends. Once everybody has left, it starts a fresh match 30 seconds later. With several `--scenario`, each next match is the next scenario in the list, then back to the first; every player is taken into it. <Key k="Ctrl" /> + <Key k="C" /> closes it and tells every player why.

```
hardlock_server.exe --scenario Duel --scenario Escalation --scenario "Two-ship"
```

## While you are connected

A line at the top of the screen says so: **CONNECTING TO**, then **ONLINE** with the server's name and your ping. A host sees **HOSTING** with the port and how many have joined. Going back to the title screen leaves the match. If the server closes or the connection drops, you go back to the MULTIPLAYER screen (the title, if you joined from the command line) and are told why.

## Chat and the scoreboard

Hold <Key k="P" /> for the scoreboard: every pilot in the match, blue and red apart, with their kills, jets lost, hits for rounds fired, and ping. Your own row is lit; **DOWN** marks a pilot waiting on their next jet, **OUT** one with none left. It works on the debrief too.

<Key k="J" /> opens the chat line over the radar scope. Type, then <Key k="Enter" /> to send, or <Key k="Esc" /> to close it. <Key k="Tab" /> switches between **ALL** (everyone) and **TEAM** (your side only; the line is marked TEAM). While the line is open your keys type instead of flying, firing or dropping flares; the mouse still steers. Lines fade after 12 seconds, and the open chat shows the last ten. The chat also tells you who joins, on which side, and who leaves.

A pilot who joins with a callsign already taken gets a number after it (Viper 2). Lines are up to 160 characters, and five in five seconds is the most a pilot can send.

## The match

Every pilot plays the scenario's rules as in a match of their own. You have its jets to lose, and when yours goes down you watch the wreck and ask for the next one, as [offline](/world/outcomes/). The kills, rounds and hits on your debrief are yours alone; the waves, the clock and the objectives belong to everyone.

When your last jet is down and others still fly, the HUD reads **NO JETS LEFT · THE OTHERS FLY ON** and you watch the rest of the fight. The match is lost only when **nobody has a jet left**: it ends 4 seconds after the last one falls, as ALL JETS LOST. A pilot alone in a match still waits on their wreck before the debrief, as offline.

The scenarios are written for the blue side. A pilot who joins on red fights against it, and wins when blue loses: their debrief reads VICTORY under **RED WINS**, and blue's win reads DEFEAT under **BLUE WINS**.

### Dogfight

For pilots against pilots, host the **Dogfight** scenario, or any scenario set to the DOGFIGHT mode in the [editor](/world/scenarios/#how-a-match-is-won). Blue fights red. Each aircraft of the other side your side brings down is a point, pilots and computer pilots alike; a crash or friendly fire scores nothing. The first side to the score limit wins, or the side ahead when time runs out, and level is a **DRAW**. Jets are unlimited unless the scenario says otherwise; a side whose every pilot is out of jets loses. The mission block on the HUD reads your side's points first, then the other side's and the limit (BLUE 3 · RED 2 · TO 10). Turn **Computer pilots** off in the editor's RULES for pilots only.

The chat tells everyone who shot down whom and with what (Viper shot down Maverick (AIM-120C-7)), who was shot down by a computer pilot, and who crashed.

### Other pilots on the HUD

The **PILOTS** block on the right lists every other pilot with **FRIEND** or **HOSTILE** and their range, or DOWN. A friend gets the friend ring with their callsign, as a friendly flight does, at any range out to 60 km, and shows on the radar scope as a friendly. A hostile pilot shows only when you can see them: the spotting mark within 8 km with a clear line of sight, with their callsign under it. On the radar a pilot is a track like any other.

On the red side the HUD is red's: the red computer pilots are your FRIENDLIES and the blue ones your TARGETS.

After the debrief, the host's RESTART starts the next match for everyone, CHANGE MATCH sets up another one, and LEAVE (<Key k="Esc" />) ends the session for all. A joined game's debrief reads NEXT MATCH SOON and puts you back in the air when the next match begins; LEAVE takes you off the server. A joined game's pause menu has **LEAVE THE MATCH** in place of the main menu, and no restart: the host runs the match.

## Reaching the host

The other players' games must reach the host's UDP port.

- **On the same home network** the game appears under ON YOUR NETWORK by itself. Its local address works too (`ipconfig` in a Command Prompt shows it as the IPv4 address).
- **Over the internet** the host's game asks the router to open the port and gives the join code. A router with UPnP turned off, or that refuses, needs the UDP port forwarded to the host's PC by hand; the others then join at the host's public address.
- **A provider's shared address.** Some internet connections put the router itself behind the provider's own network (the chat says "The router is behind your provider's own network"). No port the host opens is reachable then. Have a friend whose connection can host do it, run a server on a machine with an address of its own (a rented server), or join a virtual network app together (such as Tailscale, ZeroTier or Radmin VPN) and use the address it gives the host.
- The first time you host, Windows Firewall asks whether to let the game use the network. Allow it, or nobody can join.
- Each pilot who joins costs the host about 25 KB/s of upload in a small match and about 50 KB/s in a full one (32 pilots), whether or not the guns are firing. A home connection with 5 Mbit/s up carries a dozen pilots; a large server is best on a machine with a fast line.

Everyone must play the same version of the game. A different one is turned away with "The server runs another build of the game".

## From the command line

The same sessions start from a Command Prompt in the game's folder:

```
Hardlock.exe --host 27020 --name Viper
Hardlock.exe --connect 192.168.1.20 --name Maverick --team red
```

`--host` skips the title and hosts the match the menus have set up (the port is optional). `--connect` joins the address given; leave out `--team red` to fly on the blue side.

## Good to know

- A networked match never pauses: the menu opens, but the fight goes on around you. The simulation speed setting stays at normal.
- Your own jet answers your controls at once. Everything else is drawn where the server had it a tenth of a second ago, so the picture stays smooth. Your cannon rounds are judged against the aircraft where your screen showed them, so aim at what you see.
- P and J are keybinds: change them under Settings, Keybinds, as Pilots and Chat.

- A fit your jet can't carry is put right by the host: a pair goes back to its standard load and a missile the jet can't carry to its standard one.
